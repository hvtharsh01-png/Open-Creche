# Open Creche Network (demo portal)

Concept prototype of the **Open Creche Network**, a proposed Digital Public Good for childcare: one open marketplace where the
**State** says *where* creches are needed, certified **NGOs / NFPs** say *how* they will run them, **CSR funders** say *what* they will fund,
and an independent **Auditor** verifies the impact. Built in the same stack and style as the Sakhi Niwas Connect prototype, in a blue and pink theme.

## Pages

| Page | Route | What it does |
| --- | --- | --- |
| Login | `/login` | Left: hero photo (drop your own at `public/login-hero.jpg`, otherwise a built-in illustration shows). Right: pick **State / NFP-NGO / CSR / Auditor / Ministry admin**, then Enter. First visit lands here; "Sign out" in the role menu returns to it. Demo sign-in checks nothing. Partner logos (`public/partners/mwcd.png`, `palna.png`) show only if files exist, so add them only with written permission |
| Home | `/` | Hero + smart search, headline numbers, "I am a…" role cards, 5-step how-it-works, Odisha pilot proof, highest-need opportunities. EN / हिंदी toggle |
| Explore | `/explore` | The one search page for everyone: smart search ("rural creches in Keonjhar under ₹20 lakh"), state / district / stage / priority / cost / creche-model filters, **"within X km of me"** (location, city or map click), list + India map |
| Opportunity | `/opportunity/:id` | One creche project: 6-step lifecycle, funding, awarded operator, tripartite agreement and milestones, audit note, activity, and a **role-aware action panel** (award / bid / fund / start operating / audit) |
| My workspace | `/workspace` | Per role: State pipeline + create opportunity; NFP empanelment checklist (submit, then the Ministry approves) + recommended bids; CSR matched basket + commitments; Auditor queue; **Ministry admin**: empanelment queue, master data (standard cost per creche model), platform activity |
| Impact | `/impact` | Public dashboard: funnel, state demand and funding, creche models, audit outcomes, Odisha pilot need, rollout phases, module coverage |

Every role gets its own Home (tasks handed to it, its numbers, its place in the journey), its own Explore quick views, and its own numbers on Impact.
The **bell** shows hand-overs from other roles and the **(i)** button explains what the signed-in role can do. Permissions are enforced by the API (`x-role` header): for example only a State user can publish or award, only a CSR funder can fund.
The **Ministry admin** has a **Platform walkthrough** pop-up (Home and My workspace) that runs the six-step story as each role in turn and shows who got notified at every step. It also holds **Reset demo data**. English / Hindi works on every page; text generated by the server (notification sentences) stays in English.

## Stack

React 18 + TypeScript, Vite, Tailwind CSS v4, Framer Motion, Highcharts, Leaflet / react-leaflet, Express (TypeScript, run with `tsx`).

## Run locally

```bash
npm install
npm run dev        # API on :4001, web on http://localhost:5174
```

Production-style run (single port):

```bash
npm run build
npm start          # http://localhost:4001
```

## Layout

```
shared/    types + geo helpers used by both sides
server/    Express API, in-memory data (data.ts), matching engine (matching.ts)
src/       pages, components, Leaflet icons, Highcharts theme
api/       Vercel serverless entry (same Express app)
```

## Matching model (`server/matching.ts`)

Rule-based and explainable. Hard filters first, then a weighted score whose parts are shown in the UI as "Why this match". No AI decides where money goes.

- **NFP ↔ opportunity:** 30% area & reach, 25% creche-model experience, 20% audit record, 15% free capacity, 10% cost fit, plus up to +5 fairness boost for high-need places.
- **CSR ↔ opportunity:** 30% location (near the company's sites or in preferred states), 20% creche model, 20% budget fit, 20% need & priority, 10% readiness.
- **Fund a state programme:** greedy basket by score within the budget (swap for an assignment / stable-matching solver for large batch rounds).

The weights are proposals for the demo, not taken from the deck.

## Data disclaimer

All opportunities, operators, funders, amounts, bids and audit results are **synthetic**. From the proposal deck: the Odisha pilot district figures
(Keonjhar / Sundargarh / Jajpur, % children under 5 stunted / wasted / underweight), the pilot results (25% fewer underweight, 64% fewer wasted, about ₹42 per child per day),
the headline national scale numbers (mock-up screens), and the rollout phase table (re-checked against the scan). 20 children per creche is the deck's own ratio (100 creches = 2,000 children).
Stunted vs underweight for the pilot districts: the slide table and the written proposal list the first and third values in opposite order; the portal follows the slide. Confirm with the source.
Aadhaar / e-KYC, contract e-signing, payments and SMS / WhatsApp notifications are **simulated**. The API has no authentication; production needs role-based login.
